# تحويل جهاز المكتب إلى خادم للنظام

مناسب لشركة صغيرة. النظام خفيف جداً، فأي جهاز حديث (4 جيجا رام فما فوق) يكفي. الفرق عن الخادم المستأجر: الجهاز عندك فيتأثر بانقطاع الكهرباء والإنترنت، ونسخك الاحتياطية عليك.

## الخطوة 1 — تجهيز الجهاز (مرة واحدة)
1. **أوقف أي نافذة PowerShell** تشغّل فيها `npm.cmd start` يدوياً.
2. افتح PowerShell **كمدير** (كليك يمين ← Run as administrator) ثم:
   ```
   cd C:\erp
   powershell -ExecutionPolicy Bypass -File deploy\windows\setup-office-server.ps1 -BackupCopyTo "D:\ERP-Backups"
   ```
   غيّر `D:\ERP-Backups` إلى قرص خارجي أو مجلد مشاركة أو مجلد OneDrive (أو احذف الخيار لو ما عندك مكان بعد).
3. السكربت: يشغّل النظام تلقائياً عند تشغيل ويندوز (بدون تسجيل دخول) ويعيد تشغيله لو توقف، يجدول نسخة احتياطية يومية الساعة 2:30 ويحتفظ بآخر 30 يوماً (وينسخها للمكان الثاني)، يمنع السكون، ويفتح المنفذ 3000 لشبكة المكتب. ثم يطبع عناوين الدخول من داخل المكتب مثل `http://192.168.1.20:3000`.
4. **ثبّت عنوان الجهاز** حتى لا يتغير: من إعدادات الراوتر اعمل "حجز DHCP" (DHCP reservation) للجهاز.
5. في إعدادات الجهاز (BIOS): فعّل **Restore on AC power loss / Power On** ليعود للعمل تلقائياً بعد انقطاع الكهرباء. ويفضّل جهاز **UPS** صغير.
6. في Windows Update اضبط "Active hours" على ساعات الدوام حتى لا يعيد التشغيل أثناء العمل. وفضّل الاتصال **بالكيبل** وليس الواي فاي.

**النتيجة:** الموظفون داخل المكتب يفتحون العنوان من متصفحاتهم. كم جهاز تريد؟ كلهم يستخدمون نفس العنوان.

## الخطوة 2 — الوصول من خارج المكتب (على نطاقك، مجاناً)
الطريقة الأفضل: **Cloudflare Tunnel**. لا تفتح منافذ في الراوتر، وبدون IP ثابت، مع HTTPS تلقائي، وبياناتك تبقى على جهازك.

**شرطها:** نطاقك لازم يُدار من Cloudflare (مجاني): تنقل **Nameservers** النطاق إليهم. ⚠️ قبل النقل، دوّن كل سجلات DNS الحالية (خاصة **MX وSPF وDKIM** للإيميل)، وتأكد في Cloudflare أنها نُسخت كلها قبل تغيير الـNameservers، وإلا يتعطل بريد الشركة والموقع. إن كان هذا مقلقاً اسأل مزوّد نطاقك أو مدير موقعك.

1. أنشئ حساباً مجانياً في cloudflare.com وأضف نطاقك واتبع خطوات نقل الـNameservers.
2. لوحة Cloudflare ← **Zero Trust** ← Networks ← **Tunnels** ← Create a tunnel (Cloudflared) ← اسمه `trigon-erp`.
3. اختر **Windows**، وانسخ أمر التثبيت الذي يظهر. افتح PowerShell كمدير على جهاز المكتب ونفّذ:
   ```
   winget install Cloudflare.cloudflared
   cloudflared.exe service install <الرمز الطويل الذي نسخته>
   ```
4. في تبويب **Public Hostname** أضف: Subdomain `erp` + Domain نطاقك + Service: `HTTP` و`localhost:3000`.
5. أعد تشغيل سكربت الخطوة 1 مع الخيار `-Tunnel`:
   ```
   powershell -ExecutionPolicy Bypass -File deploy\windows\setup-office-server.ps1 -Tunnel -BackupCopyTo "D:\ERP-Backups"
   ```
6. افتح `https://erp.نطاقك.com` من أي مكان. **رمز الإعداد** يظهر في آخر السكربت (وهو محفوظ في `C:\erp\data\setup-token.txt`) ولا تحتاجه إلا لإنشاء مدير جديد على قاعدة بيانات فارغة.

**بديل أبسط بدون تغيير الـDNS:** برنامج **Tailscale** (مجاني للاستخدام الصغير): تثبّته على جهاز المكتب وعلى أجهزة من تريد، فيدخلون كأنهم في المكتب، والنظام غير منشور للعموم. مناسب للإدارة فقط، أما بوابة الموظفين فتحتاج Cloudflare Tunnel.

## قائمة أمان وموثوقية
- 🔒 كلمة مرور قوية لحساب ويندوز، وفعّل **BitLocker** لتشفير القرص (لأن فيه بيانات رواتب).
- 🔒 اترك **Windows Defender** والتحديثات شغالة، ولا تستخدم الجهاز للتصفح العام.
- 💾 انسخ مجلد `C:\erp\data\backups` إلى **مكان خارج الجهاز** (قرص خارجي أو OneDrive). النسخة على نفس الجهاز لا تحميك إن تعطل أو سُرق.
- 🧪 جرّب الاسترجاع مرة: انسخ أحدث ملف نسخة إلى جهاز آخر وسمّه `erp.db` داخل مجلد `data`.
- 🔁 بعد كل تحديث للنظام: انسخ الملفات الجديدة فوق `C:\erp` (بدون مجلد `data`) ثم من PowerShell مدير: `schtasks /End /TN TrigonERP` ثم `schtasks /Run /TN TrigonERP`.

## متى تنتقل إلى خادم مستأجر؟
لو كبر عدد الموظفين، أو صار الانقطاع مكلفاً، أو احتجت وصولاً مضموناً 24/7: النقل سهل (انسخ `erp.db` وفق `DEPLOY.md`).
