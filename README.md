# نظام إدارة شركة مقاولات — Contractor ERP (UAE)

بديل بسيط لـ Zoho/Odoo لشركة مقاولات صغيرة في الإمارات. بدون اشتراكات، بدون مكتبات خارجية، والبيانات على جهازك.

## التشغيل
```bash
node --version      # يلزم Node.js 22.5 أو أحدث
npm start           # ثم افتح http://localhost:3000
npm test            # اختبارات الحسابات والامتثال
```
أول مرة: أنشئ حساب المدير، ثم **الإعدادات** وأدخل: TRN، رقم المنشأة (MOHRE)، رمز توجيه البنك، IBAN.
البيانات في `data/erp.db` — حمّل نسخة احتياطية من الإعدادات بشكل دوري.

## الامتثال — ما هو مطبّق وما يجب مراجعته
مطبّق: فاتورة ضريبية بالحقول المطلوبة، منع حذف الفواتير، التحقق من TRN/الهوية/بطاقة العمل/رمز التوجيه/IBAN (MOD-97)، أجر ساعة الأوفرتايم +25%/+50%، نهاية الخدمة (21/30 يوم وسقف سنتين)، قفل الرواتب بعد الاعتماد، سجل تدقيق.

**غير معتمد رسمياً** من FTA أو MOHRE أو المصرف المركزي. قبل أول استخدام راجع مع محاسب قانوني وبنكك:
- صيغة ملف SIF واسمه (تختلف تفاصيلها بين البنوك) — اطلب من البنك التحقق من أول ملف.
- معالجة ضريبة المحتجزات (توقيت التوريد) والتعديلات الضريبية لضريبة الشركات.
- الفوترة الإلكترونية (Peppol) غير مدعومة بعد.

## النشر أونلاين (النطاق الخاص بك)
1. استأجر خادماً صغيراً (VPS) أو خدمة تدعم Docker مع **قرص دائم** لمجلد `/data` (البيانات في SQLite).
2. `docker build -t erp . && docker run -d --restart=always -p 3000:3000 -v erp-data:/data erp`
3. وجّه نطاقاً فرعياً مثل `erp.yourdomain.com` (سجل A) إلى الخادم، وضع أمامه Caddy أو Nginx لتفعيل **HTTPS** (شهادة مجانية). الكوكيز تصبح Secure تلقائياً خلف HTTPS.
4. متغيرات اختيارية: `PORT`, `HOST` (استخدم `127.0.0.1` خلف الوكيل), `DATA_DIR`, `TRUST_PROXY=1`, `SECURE_COOKIES=1`.
5. خذ نسخة احتياطية من الإعدادات بانتظام، ولا تفتحه على الإنترنت بدون HTTPS.
الحماية المدمجة: تجزئة كلمات المرور (scrypt)، قفل بعد 8 محاولات دخول فاشلة، وكوكيز HttpOnly/SameSite.

## الأدوار والبريد
- **الأدوار:** مدير النظام (كل شيء) • محاسب (كل شيء عدا المستخدمين والإعدادات) • مدير مشاريع (المشاريع، BOQ، اليومية، عروض الأسعار؛ بدون رواتب أو ضرائب) • عرض فقط. تُضبط من **الإعدادات ← المستخدمون**، والصلاحيات تُفرض على الخادم وليس في الواجهة فقط.
- **البريد:** من **الإعدادات ← إرسال البريد الإلكتروني** أدخل بيانات SMTP لبريد شركتك (Microsoft 365 / Google Workspace / استضافة الدومين) ثم أرسل رسالة تجريبية. الفاتورة تُرسل كنص HTML داخل الرسالة (بدون ملف PDF مرفق).
