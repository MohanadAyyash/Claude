# نظام إدارة شركة مقاولات — Contractor ERP (UAE)

بديل بسيط لـ Zoho/Odoo لشركة مقاولات صغيرة في الإمارات. بدون اشتراكات، بدون مكتبات خارجية، والبيانات على جهازك.

## التشغيل
```bash
node --version      # يلزم Node.js 22.5 أو أحدث
npm start           # ثم افتح http://localhost:3000
npm test            # اختبارات الحسابات والامتثال
```
أول مرة: أنشئ حساب المدير، ثم **الإعدادات** وأدخل: TRN، رقم المنشأة (MOHRE)، رمز توجيه البنك، IBAN.
البيانات في `data/erp.db` — حمّل نسخة احتياطية من الإعدادات بشكل دوري.

## الوحدات
| الوحدة | الوظيفة |
|---|---|
| المشاريع | قيمة العقد، الإمارة، الربحية والهامش لكل مشروع |
| عروض الأسعار | بنود، ضريبة لكل بند، طباعة PDF، تحويل لمشروع بنقرة |
| فواتير ضريبية | ترقيم تسلسلي، TRN، محتجزات (Retention)، إشعار دائن، إلغاء بسبب (لا حذف) |
| المصروفات والمشتريات | موردون ومقاولو باطن، ضريبة مدخلات، تكلفة لكل مشروع |
| المدفوعات | مقبوضات ومدفوعات، شيكات (قيد التحصيل/مرتجع)، تحرير محتجزات |
| الموظفون والرواتب | بيانات WPS، أوفرتايم، نهاية الخدمة، ملف **SIF**، تنبيه انتهاء الإقامة/الهوية/الجواز |
| ضريبة القيمة المضافة | أرقام VAT 201 حسب الإمارة، صفري/معفى، مدخلات/مخرجات |
| ضريبة الشركات | تقدير 9% فوق 375,000 + إعفاء المنشآت الصغيرة |
| الامتثال والتدقيق | تنبيهات، مواعيد، سجل تدقيق لكل عملية |

## الامتثال — ما هو مطبّق وما يجب مراجعته
مطبّق: فاتورة ضريبية بالحقول المطلوبة، منع حذف الفواتير، التحقق من TRN/الهوية/بطاقة العمل/رمز التوجيه/IBAN (MOD-97)، أجر ساعة الأوفرتايم +25%/+50%، نهاية الخدمة (21/30 يوم وسقف سنتين)، قفل الرواتب بعد الاعتماد، سجل تدقيق.

**غير معتمد رسمياً** من FTA أو MOHRE أو المصرف المركزي. قبل أول استخدام راجع مع محاسب قانوني وبنكك:
- صيغة ملف SIF واسمه (تختلف تفاصيلها بين البنوك) — اطلب من البنك التحقق من أول ملف.
- معالجة ضريبة المحتجزات (توقيت التوريد) والتعديلات الضريبية لضريبة الشركات.
- الفوترة الإلكترونية (Peppol) غير مدعومة بعد.
