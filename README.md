# نظام إدارة شركة مقاولات — Trigon Civil Contracting ERP (UAE)

نظام متكامل لشركة مقاولات إماراتية صغيرة: مشاريع، مبيعات، مشتريات، مخزون، موارد بشرية ورواتب WPS، محاسبة، وامتثال ضريبي.
بدون اشتراكات وبدون مكتبات خارجية، والبيانات على جهازك (أو خادمك).

## التشغيل
```bash
node --version      # Node.js 22.5 أو أحدث
npm start           # ثم افتح http://localhost:3000   (ويندوز: npm.cmd start)
npm test            # اختبارات الحسابات والصلاحيات والامتثال
```
أول مرة: أنشئ حساب المدير، ثم **الإعدادات**: الاسم الرسمي، TRN، رقم المنشأة (MOHRE)، رمز توجيه البنك، IBAN، ثم ارفع **الشعار والختم والتوقيع**.
البيانات في `data/erp.db` (تشمل المستندات المرفقة). بعد كل تحديث للكود أعد تشغيل الخادم.

## الوحدات
| المجموعة | المحتوى |
|---|---|
| المشاريع والمبيعات | مشاريع، BOQ بنسبة إنجاز وفوترة إنجاز، أوامر تغيير، عروض أسعار، فواتير ضريبية، إشعارات دائنة، يومية الموقع |
| المشتريات والمخزون | طلبات أسعار RFQ مع مقارنة الموردين ← أمر شراء ← فاتورة مورد، مقاولو الباطن وشهادات الدفع (محتجزات/دفعة مقدمة)، مخزون بمتوسط التكلفة، أصول وإهلاك، عهدة نقدية |
| المحاسبة | قيود تُولَّد تلقائياً من المستندات + قيود يدوية، دفتر أستاذ، ميزان مراجعة، قائمة دخل ومركز مالي، دليل حسابات، مطابقة بنك (CSV)، تصدير Excel لكل التقارير |
| الموارد البشرية | موظفون ومستنداتهم، إجازات وأرصدة حسب القانون، طلبات الموظفين، حضور وإضافي يغذّي الرواتب، خطابات رسمية (شهادة راتب، NOC، خبرة…) بأرقام مرجعية، رواتب وملف WPS (SIF)، قسائم راتب |
| بوابة الموظف | الموظف يرى رصيد إجازاته وقسائمه ويقدّم طلباته فقط |
| الضرائب والامتثال | VAT 201 حسب الإمارة، تقدير ضريبة الشركات، تنبيهات انتهاء الرخصة/الإقامات/المستندات، جاهزية الفوترة الإلكترونية، سجل تدقيق |

## الهوية والطباعة
الشعار والختم والتوقيع (الإعدادات ← هوية الشركة) تظهر تلقائياً في كل المستندات الصادرة: الفواتير، عروض الأسعار، أوامر الشراء، شهادات الباطن، الخطابات، قسائم الراتب. أي صفحة أو تقرير يُطبع بالترويسة من زر **طباعة بالترويسة**.
ملفات PDF (للتحميل ومرفقات الإيميل) تُولَّد عبر Chrome/Edge المثبّت على الجهاز؛ إن لم يوجد يُرسَل الإيميل بنص HTML فقط (يمكن تحديد المسار بالمتغير `CHROME_PATH`).

## الأدوار
مدير النظام (كل شيء) • محاسب • مدير مشاريع • موارد بشرية • عرض فقط • موظف (بوابته فقط). الصلاحيات تُفرض على الخادم، ولا يرى الموظف أو مدير المشاريع بيانات الرواتب أو الحسابات.

## الامتثال — ما هو مطبّق وما يجب مراجعته
مطبّق: فاتورة ضريبية بالحقول المطلوبة وترقيم تسلسلي ومنع الحذف (إلغاء/إشعار دائن)، التحقق من TRN/الهوية/بطاقة العمل/رمز التوجيه/IBAN، أجر ساعة الإضافي +25%/+50%، نهاية الخدمة 21/30 يوم وسقف سنتين، رصيد الإجازة (يومان/شهر بعد 6 أشهر، 30 يوم/سنة)، قفل الرواتب، سجل تدقيق.

**غير معتمد رسمياً** من FTA أو MOHRE أو المصرف المركزي. راجع مع محاسب قانوني وبنكك قبل الاعتماد:
- صيغة ملف SIF واسمه (تختلف بين البنوك) — اطلب من البنك التحقق من أول ملف.
- معالجة ضريبة المحتجزات والتعديلات الضريبية لضريبة الشركات؛ القوائم المالية إدارية وغير مدققة.
- الفوترة الإلكترونية (Peppol) تتم عبر مزوّد خدمة معتمد ولا يرسل النظام إليها بعد؛ يوجد فحص جاهزية فقط.
- نصوص الخطابات قياسية؛ راجعها قبل التوقيع. وحماية بيانات الموظفين (PDPL) مسؤوليتك عند الاستضافة.

## النشر أونلاين (النطاق الخاص بك)
1. خادم VPS صغير مع قرص دائم لمجلد `/data`.
2. `docker build -t erp . && docker run -d --restart=always -p 3000:3000 -v erp-data:/data erp`
3. نطاق فرعي (سجل A) مثل `erp.yourdomain.com` + Caddy أو Nginx لتفعيل **HTTPS** (مطلوب خصوصاً لبوابة الموظف).
4. متغيرات: `PORT`, `HOST`, `DATA_DIR`, `TRUST_PROXY=1`, `SECURE_COOKIES=1`, `CHROME_PATH`.
5. حمّل نسخة احتياطية بانتظام (الإعدادات ← نسخة احتياطية). الحماية المدمجة: تجزئة كلمات المرور (scrypt)، قفل بعد 8 محاولات فاشلة، كوكيز HttpOnly/SameSite.
